# Experimental cooperative start boundary

In experimental group mode, `MongoEventStoreService` uses `CooperativeDispatcher` with process-local shared transaction admission. Its injected runner waits for admission, then calls `finalize()` synchronously, immediately before its first session or transaction operation, with no intervening await. A missing batch means no work may start. The runner must not start session work before finalization, call it more than once, or retain it beyond its own lifetime. These obligations are cooperative, not enforceable against an untrusted runner.

Until finalization, members remain dispatcher-owned and compactable: cancellation/deadline removes them and releases their reservation. Finalization rechecks elapsed deadlines synchronously, selects distinct keys, and seals the remaining members atomically in the JavaScript event loop. Arrivals while admission is waiting can join the candidate group. After finalization cancellation or deadline reports unknown and does not remove the member; batch capacity and bytes remain reserved until the runner has returned after cleanup. A runner rejection after finalization retains capacity indefinitely, failing closed. Shutdown cancels pre-start members and prevents subsequent finalization; after finalization its timeout reports unknown but does not release an owned batch until cleanup. The runner must settle the batch and return only after cleanup has completed; if cleanup cannot be confirmed it must reject or remain pending.

Ordinary appends, deletes, tombstones and individual scavenge transactions share the same FIFO admission as grouped appends. Admission is bounded to 256 owners/waiters and 16 MiB estimated request bytes; the group queue has its own limits. A lease is released only after driver session cleanup completes; unconfirmed cleanup retains it indefinitely. Waiting cancellation and deadlines prevent starting work; after start they report unknown without releasing the lease. Shutdown rejects waiters and bounds the admission drain wait. This remains experimental, process-local, and does not fence other adapters or prove server abort acknowledgement.
